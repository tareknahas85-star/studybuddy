# StudyBuddy: رفيقك بالدراسة 📒

تطبيق أندرويد عربي لدراسة الأولاد. كل طالب إلو **رفيق** بيختاره، وكتب حقيقية بتنحط عالرف، ودروس بتنعمل من صور صفحات كتابو المدرسي بمساعدة جيميني. بلا إعلانات وبلا تتبّع، وكل الداتا على تلفون الطفل.

## شو فيه

- **رفقاء بيتفتحوا بالنجوم**: بودي وياسمينة من البداية، وبعدين سلحفوش وروبو وفانوس وميمي (قطة) ولولو (أرنب) وبندق (باندا) ودينو وبوبو (بومة). ومعهم إضافات وثيمات.
- **مكتب وكتب حقيقية**: رف كتب، غلاف بينفتح، وفهرس بالدروس.
- **الدرس صفحة بصفحة**: شرح قصير، "اشرح غير شكل"، أسئلة خيارات، و"مين الغلطان؟". الغلط مو عقوبة.
- **ناقش رفيقك بالدرس**: محادثة كتابة أو رسالة صوتية.
- **مراجعة اليوم**: الأسئلة اللي غلط فيها الطالب بترجع بعد يوم وتلاتة وسبعة وأربعتعش يوم.
- **علّم رفيقك** و**اقرا بصوتك**: الطالب بيشرح للرفيق، والرفيق بيسمع القراءة بيصحّح النطق بلطف.
- **نجوم صعبة**: بس من دروس الكتب، بدقيقة على الأقل، وسقف يومي، وكل صفحة مرة وحدة. ومعها مهمّات بمراحل ومستويات وهدف أسبوعي.
- **قسم الأهل بقفل رمز** (٤ لـ ٦ أرقام): تقدم الأسبوع، الذاكرة، ملخص اليوم، حد دراسة، واجب مصوّر، وإدارة الكتب، ومفتاح جيميني.
- **نسخة احتياطية ZIP** لكل بيانات الطالب، وبترجّعها على أي تلفون.
- **تحديث من التطبيق**: بانر "في نسخة جديدة" عند الفتح، والتحديث بيتثبّت فوق النسخة الحالية وبياناتك بتضل.

## التثبيت

1. نزّل الـAPK من صفحة [Releases](../../releases/latest) وثبّتو على تلفون الطفل.
2. أول تشغيل: اختار رمز الأهل، وبعدين أدخل الطفل (اسمو، رفيقو، صورتو).
3. من قسم الأهل (القفل فوق يسار): حط حد الوقت، والواجبات، وهدف الأسبوع، ومفتاح جيميني المجاني من [Google AI Studio](https://aistudio.google.com/app/apikey).

## نقل البيانات لتلفون جديد

1. من قسم الأهل ← نسخة احتياطية ← صدّر (ZIP).
2. على التلفون الجديد: ثبّت التطبيق ← قسم الأهل ← استيراد نسخة.

## للمطوّر

```bash
npm ci --include=dev
npm run dev        # http://localhost:5173
npm test           # اختبارات المنطق
npm run build      # typecheck + vite build
```

- كل push على `main` بيشغّل GitHub Actions: فحص الأنواع، الاختبارات، البناء، وAPK موقّع، وبينشر Release باسم `v<version>` من `package.json`.
- التوقيع بمفتاح ثابت من أسرار المستودع. ما بينحط مفتاح بالكود أبداً.
- على ويندوز لا تبني من مجلد Google Drive.

```
src/
  App.tsx            # الحالة والتنقل
  lib/               # store، ai (جيميني)، companions، rewards، security (الرمز)، notify، backup، update
  components/        # Setup، Who، Desk، BookView، LessonPlayer، LessonChat، Album، Game، Review، Teach، ReadAloud، Missions، Parent، Sheets
tests/               # اختبارات المنطق
```
